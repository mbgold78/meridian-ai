# Substrate operator guide (D3)

Seven hands-on tasks for the Meridian engagement operator — the person with a
terminal open on the machine that runs Substrate. Each task is car-manual
style: numbered steps, one screenshot per UI step (regenerated by the docs
pipeline, never hand-captured), terminal steps shown exactly as they ran in
the committed acceptance evidence, and a closing **"You'll know it worked
when…"** naming the observable end state.

| # | Task | File |
|---|------|------|
| 1 | First boot: empty vs seeded, profile selection, port management | [01-first-boot.md](01-first-boot.md) |
| 2 | Ingest the Glacier sample corpus end to end (convert → stage → review → commit) | [02-corpus-ingest.md](02-corpus-ingest.md) |
| 3 | Run a diagnostic, curate findings, walk the provenance chain | [03-diagnostics.md](03-diagnostics.md) |

## Conventions used by every task

**Where commands run.** From the `substrate/` directory of the deployment
checkout. Windows: `.\gradlew.bat`; macOS/Linux: `./gradlew`. REST examples
use `curl` against `http://localhost:8080` — substitute your port.

**The demo boot posture.** Tasks 4–7 run against a seeded instance booted
exactly like the docs capture pipeline boots it:

```powershell
cd substrate
.\gradlew.bat :app:bootJar
java -jar app\build\libs\app-0.1.0.jar --spring.profiles.active=dev `
  --substrate.demo.seed=true --substrate.demo.contracts.activate=true `
  --substrate.demo.fixed-clock=2026-05-12T00:00:00Z --server.port=8080
```

The fixed clock pins every date-relative computation to a proven instant
(the April contract breach is detectable, the lifecycle-stall count stays 0)
so what you see matches this guide byte for byte. Tasks 2–3 use the
`dev-shared` profile instead — they need the ingestion CLI and the app on
one shared database.

**Identity on writes.** The API takes actor identity from persona headers
(spoofable by design in the current phase; OIDC replaces the source later):

```text
-H "Content-Type: application/json"
-H "X-Persona-Id: operating-partner"
-H "X-Persona-Label: Operating Partner"
```

Every state-changing request body also requires an `idempotencyKey` (any
unique string; replaying the same key returns the original result without
duplicating the action).

**Terminal blocks are evidence, not illustrations.** Every captured output
in these tasks is quoted from a committed acceptance transcript under
`substrate/docs/acceptance/` (per-task pointers at the bottom of each file).
If your output disagrees in shape, trust the transcript and check your boot
flags first.

**Screenshots are build artifacts.** Image references resolve after
`gradlew docsAssemble` (which runs `docsCapture` first); they are never
checked in. Each capture's spec lives in `substrate/docs/pipeline/specs/`
and doubles as a UI regression gate — if a documented surface breaks, the
docs build fails naming the task and spec.

**One vocabulary note before anything else.** A documented "no" — a declined
cascade, a declined contract, a rejected finding, a rejected promotion
review — is a legitimate outcome, never an error. Expect HTTP 200 on
declines and reddish accents to mean *leader attention*, not *failure*.
